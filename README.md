# SaaS Subscription Analytics Platform

Projeto de análise de assinaturas SaaS utilizando PostgreSQL, MongoDB, Docker, DBeaver e VS Code.

## Objetivos

- Modelagem relacional
- SQL avançado
- Procedures
- Triggers
- Views
- Performance tuning
- Métricas SaaS (MRR, ARR, Churn e Retention)

## Stack

- macOS Tahoe
- Apple Silicon M1
- PostgreSQL
- MongoDB
- Docker Desktop
- DBeaver
- VS Code
